# ClimaGlass 🌤️

A modern, glassmorphism-inspired weather web application built with vanilla JavaScript, HTML, and CSS. It provides real-time weather updates with a clean, animated user interface.

## ✨ Features

- **Real-Time Data:** Accurate current temperature and weather conditions.
- **Detailed Metrics:** Displays humidity, wind speed, and precise sunrise/sunset times.
- **Modern UI:** Glassmorphism design system with responsive layouts.
- **Smooth Animations:** Fluid transitions and floating icons for a dynamic user experience.

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations, Backdrop-filter)
- Vanilla JavaScript (ES6+, Fetch API, Async/Await)
- OpenWeatherMap API (or alternative weather API)
